# SweetBloom Cake Shop

Web Application สำหรับจัดการร้านเค้กผ่าน Docker ครบตั้งแต่ลูกค้าสั่งเค้ก ครัวอัปเดตคิว แคชเชียร์รับชำระ ไปจนถึงแอดมินจัดการเมนูและดูยอดขาย

## เริ่มใช้งาน

ครั้งแรกให้รัน `Setup Docker Backend.bat` ด้วยสิทธิ์ Administrator แล้ว restart Windows หนึ่งครั้ง จากนั้นเปิด Docker Desktop และดับเบิลคลิก `Start SweetBloom.bat` ระบบจะ build, start container และเปิด `http://localhost:4173`

หากต้องการใช้ Terminal:

```powershell
docker compose up --build -d
docker compose ps
```

หยุดระบบด้วย `Stop SweetBloom.bat` หรือ `docker compose down`

ดู log ด้วย `docker compose logs -f app`

## หน้าจอที่มี

- **หน้าร้าน** เลือกเมนู ระบุข้อความบนเค้ก นัดวันรับ เลือกรับหน้าร้านหรือจัดส่ง และติดตามด้วย token ส่วนตัว
- **ครัว** ดูคิวตามลำดับเวลา ยืนยันออเดอร์ เริ่มทำ พร้อมรับ และเสร็จสิ้น
- **แคชเชียร์** ตรวจยอดและบันทึกการชำระเงินสด บัตร หรือ QR โดยป้องกันการจ่ายซ้ำ
- **จัดการร้าน** เพิ่มเมนู ปิดขาย ปรับราคา/สต็อก ดูรายงานยอดขาย และดาวน์โหลด CSV

ข้อมูลเก็บถาวรใน Docker named volume `sweetbloom-data` แม้หยุดหรือลบ container แล้วเปิดใหม่ข้อมูลยังอยู่ ทุกแท็บที่เปิดอยู่จะอัปเดตผ่าน Server Sent Events

หน้าครัว แคชเชียร์ และจัดการร้านล็อกด้วย Staff PIN ข้อมูลลูกค้าจะไม่ถูกส่งให้หน้าร้านทั่วไป

## ตั้งค่าก่อนขายจริง

1. คัดลอก `.env.example` เป็น `.env`
2. เปลี่ยน `STAFF_PIN` ห้ามใช้ค่าเริ่มต้น `2468`
3. ใส่ `PROMPTPAY_ID` หากรับโอน PromptPay
4. ตรวจชื่อร้าน ราคา สต็อก ค่าจัดส่ง ภาษี และข้อมูลใบเสร็จให้ตรงกับกิจการ
5. หากเปิดให้อินเทอร์เน็ตภายนอกเข้าถึง ต้องวางหลัง HTTPS reverse proxy และสำรอง volume `sweetbloom-data` เป็นประจำ

ระบบปัจจุบันรองรับการบันทึกการชำระและตรวจยอดโดยพนักงาน แต่ยังไม่ได้เชื่อม Payment Gateway หรือออกใบกำกับภาษีอิเล็กทรอนิกส์อัตโนมัติ
